# BioPharma Finder Post-processing

Modular Python/Streamlit application for processing Thermo BioPharma Finder peptide-mapping results, including `.resultsbpf`, PMF and CSV imports, separate RAW-run metadata, peptide filtering, sample comparisons and exports.

> Research prototype. Native PMF parsing is experimental and must be validated against BioPharma Finder CSV exports before quantitative or regulated use.

The complete source, tests and documentation will be added in the initial project import.
